# Folders

Folders are ordinary directories on disk. There is a `projects/` folder in this
workspace with one note in it — [[projects/First project]] — and if you open the
workspace in your file manager you will find exactly that, a folder with a
`.md` file in it.

## Use them sparingly

The instinct is to build the folder tree first. It is usually wrong: you end up
deciding where something lives before you know what it is, and then moving it.

A flatter workspace plus [[Linking notes]] and [[Tags]] tends to age better. Add
a folder when one group has grown big enough that scrolling past it is annoying
— not before.

## Moving files is safe

Move a note between folders in your file manager and the wiki-links to it keep
working, because a link names the note rather than its path. That is also why
two notes with the same name in different folders need their full path to be
linked unambiguously.
