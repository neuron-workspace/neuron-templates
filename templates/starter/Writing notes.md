# Writing notes

A note is a `.md` file. This one is `Writing notes.md`, sitting in the folder you
chose when you created this workspace.

## What Markdown gives you

**Bold**, *italic*, `inline code`, and links like
[the Neuron docs](https://neuron-workspace.github.io/docs/).

- Bullet lists
- With items

1. Numbered lists
2. Also work

> A quote, for when you are citing something rather than saying it.

Task lists tick in place — click one:

- [ ] Try clicking this box in Reading view
- [x] This one is already done

## Three views

The buttons above the note switch between them:

| View | What it is for |
| --- | --- |
| Reading | The rendered result. Double-click any line to jump into it. |
| Live | Edit with formatting shown in place. |
| Split | Source on the left, rendered on the right. |

## Fenced code

Code blocks keep their whitespace and are never executed:

```bash
# your notes are just files
ls *.md
```
