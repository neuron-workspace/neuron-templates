# Start here

This workspace is a folder on your disk. Every note in it is a plain `.md` file
you could open in any other editor, and nothing here is stored anywhere else.

Five short notes, each one thing:

- [[Writing notes]] — the file, and what Markdown gets you
- [[Linking notes]] — `[[wiki-links]]` and the backlinks they create
- [[Tags]] — `#tags`, and when they beat a folder
- [[Folders]] — when a folder is the right answer instead
- [[Finding things]] — search, and the command palette

## The one idea

A note is a file. A link is text inside that file. Nothing in Neuron is a
database row you would lose by opening the folder somewhere else — which is why
you can delete this workspace, or move it to another machine, and lose nothing
but the notes you chose to delete.

Open [[Writing notes]] when you are ready.
