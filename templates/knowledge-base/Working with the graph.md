# Working with the graph

The graph draws a dot per note and a line per link. It is not a picture of your
thinking — it is a picture of what you actually wrote down, which is more
useful and less flattering.

## What to look for

**Hubs.** A note with many connections is doing real work. [[Index]] is a hub by
design. If a note you thought was minor turns out to be a hub, it is probably
several notes — see [[Atomic notes]].

**Orphans.** A note with no links is one you will never find again by
following anything. Either link it or accept it is a scrap.

**Clusters.** Groups that connect densely to each other and thinly to everything
else are subjects you did not plan. That is the moment a new
[[Maps of content]] is worth writing.

**Bridges.** A single link joining two clusters is often the most interesting
thing in the workspace: it is the connection only you have made.

## Local graph

Global view shows shape; local view shows neighbourhood. Open a note, set depth
to 1, and you see exactly what it touches. Depth 2 shows what those touch —
usually the point at which you find a note you had forgotten.

## Do not tidy it

A graph that looks neat has usually been arranged rather than written. Messiness
where the work is messy is information, and it is the reason
[[Linking over filing]] beats deciding the structure up front.
