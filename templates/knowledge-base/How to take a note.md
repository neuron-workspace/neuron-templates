# How to take a note

Two kinds, and confusing them is why knowledge bases rot.

## Notes that remember

Reference. A command you will forget, a phone number, the shape of an API. Write
it down verbatim, title it so search finds it, and never think about it again.

These do not need to be atomic and do not need links. They are lookups.

```bash
# the kind of thing worth a reference note
git log --oneline --graph --decorate --all
```

## Notes that think

Claims. Something you now believe, in your own words, with the reason attached.
These are the ones that follow [[Atomic notes]] — titled as a sentence, linked
to whatever they argue with.

The test is whether you could have written it before reading the source. If you
could not, it is thinking; if you are copying, it is remembering.

## Why the distinction matters

Reference notes filed as thinking notes clog the graph — they have no outgoing
links and never will, so they sit as orphans in
[[Working with the graph]] looking like a problem.

Thinking notes filed as reference get quoted rather than argued with, and stop
developing.

## In practice

Write the quote, then write what you make of it, and link the second one. The
source stays put; the idea joins the web described in [[Linking over filing]].
